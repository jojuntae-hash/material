# 코드리뷰 · 최신 회사 코드와 화면 테마 통합 (2026-11-08)

## 기준과 변경

- GitHub `43862eb`를 fast-forward로 반영한 후 로컬 테마/목록 변경을 적용했다. 회사 변경 8커밋을 그대로 유지했다.
- 회사 기능: 공종별 청구번호와 파일명, 기계·소방 분리 다운로드, 구분/메모 열, 행 드래그 재배치, 같은 열 Enter 이동, 빈 단위 EA 기본값.
- 화면 변경: QUIET DESK 기본값, GRID ERP/COLOR BLOCK/기존 디자인, 90–140% 글자 크기, 메뉴·본문 통합 중앙 프레임, 품명/규격 열 분리. 목록의 원자재/입고상태 표시는 제거했으며 상세·데이터는 보존했다.
- 문서 충돌은 회사 설명과 테마 설명을 모두 보존해 해결했다. 원본 코드 백업과 Git stash도 유지했다.

## 리뷰

- 업무 데이터/DB 스키마/엑셀 생성 코드는 이번 테마 커밋에서 변경하지 않는다. 화면 설정은 `mm-appearance-v1` 브라우저별 저장이며 업무 데이터와 분리된다.
- 설정값 검증과 저장 실패 처리를 확인했다. 테마는 CSS 속성만 변경하여 업무 입력 상태를 재생성하지 않는다.
- 기존 디자인 100%는 기존 색상/타이포그래피를 사용하고, 새 공통 프레임 및 요청한 목록 열 배치는 모든 테마에 적용된다.
- 잘못된 공유/라이브러리 안내를 기능 구현으로 간주하지 않는다. 대화 공유는 업무 앱의 기능과 무관하다.
- 기존 청구서 QA는 회사 변경에 맞춰 구분 선택, 두 청구번호, 메모 X열, 소방 다운로드 선택을 갱신했다. 검증 기준을 완화하지 않았다.

## 자재명 표준화 통합 추가 리뷰

`material-standard.js`를 통해 원본 보존과 표준명 투영을 분리했다. 표준명/별칭 검색, 표준 ID 기반 집계, 원본 상세, 엑셀 원본명 열 및 재업로드, 규칙 변경 시 담은 자재 연결을 검토했다. 별칭 충돌/연쇄/중복 ID를 차단하고 부분 로딩 시 규칙 저장을 막는다. 이미 변환한 이름을 직접 수정했을 때 예전 원본으로 돌아가는 문제를 방지했다. 새 품목관리의 미등록 품명 접힘 영역 때문에 생긴 기존 QA의 모호한 selector는 등록 폼에 한정하도록 보정했다.

검증: `pnpm test` 100개, `pnpm build`, `qa-material-standard.cjs`, `qa-request-composer.cjs`, `qa-mobile-menus.cjs` 84화면, `qa-composer-bulk.cjs`, `qa-tool-ledger.cjs` 통과. 테스트는 격리된 로컬 데이터로 수행했고 운영 데이터는 변경하지 않았다. 현장별 공유는 기존 저장 경로를 재사용하며 실제 운영 계정에서 기기 간 동기화는 추가 확인 대상이다.
