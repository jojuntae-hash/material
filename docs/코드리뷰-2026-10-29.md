- 기존 순서가 없는 공도구보다 신규 항목이 앞에 배치될 수 있어 기존 등록일순을 유지하고 신규 항목을 뒤에 배치하도록 수정했습니다.
- 동시에 사진을 처리하면 개수 제한이 어긋날 수 있어 처리 중 재추가를 막고, 저장 시 사진 8장·총 데이터 URL 4MiB·JPEG 형식을 검사합니다. 현장/사용자 변경 및 버전 충돌도 검사합니다.
- 사진 data URL을 새 탭으로 여는 동작은 브라우저에서 차단될 수 있어 사진을 누르면 내려받도록 바꿨습니다.
- 정상 청구 목록의 취소 건 노출을 제거하고 전용 창에서 조회합니다. 정상 목록 엑셀도 같은 조건을 사용합니다.
- 취소 목록 정렬은 공란을 마지막에 두며 숫자 수량과 한국어 자연순, 취소 시각(시간대 포함)을 구분합니다. 검색어를 유지하며 원본 데이터는 변경하지 않습니다.
- 공통 상세창 닫기 버튼 sticky, 취소 목록 수량/단위 한 줄, 상세창 하단 버튼 한 줄 배치와 모바일 표시를 확인했습니다.

### 공도구 입출고 통합 내역 (최종)
- 입고 전용 목록을 입고·지급·반납 통합 표로 확장했습니다. 날짜별 그룹 없이 한 행에 한 기록을 표시합니다.
- 열: 구분 / 공구명 / 규격 / 수량 / 입고일 / 지급일 / 반납일 / 수령자 / 메모 / 관리. 해당 유형의 날짜만 표시하고 다른 날짜는 —입니다. 색상과 구분 글자를 함께 표시합니다.
- 전체·입고·지급·반납 필터에 건수를 표시하며, 각 데이터 열 정렬과 ‘최근 처리순’ 초기화를 지원합니다. 필터 상태는 현장·사용자 변경 시 초기화됩니다.
- 표는 1,115px 고정 폭으로 과도하게 벌어지지 않게 하고 좁은 화면에서는 가로 스크롤합니다. 날짜/수량/단위는 한 줄이며 헤더는 세로 스크롤 중 고정됩니다.
- 취소된 이벤트와 보관·삭제 공도구는 제외합니다. 수정은 기존 취소/대체 이력을 보존합니다. 기존 공도구 데이터와 SQL 변경은 필요하지 않습니다.
- 테스트 71개와 빌드 통과. 브라우저에서 입고→지급→반납을 등록해 날짜 열·수령자·필터·정렬을 확인했습니다.

### 사진 확대 / 긴 규격 / 전체 메뉴 모바일 점검
- 사진 확대창은 원래 편집 dialog 위에 별도 dialog로 열어 작성 중 입력값을 보존합니다. 닫기/취소(Esc)/바깥 배경 클릭 후 원래 썸네일로 포커스를 되돌립니다. 저장된 JPEG만 허용하고 다운로드 파일 확장자를 jpg로 맞춥니다.
- 등록 공도구 및 입출고 표는 공구명·규격 줄바꿈 없이 내용에 맞춰 열이 확장됩니다. 좁은 화면은 표 내부 가로 스크롤로 표시하고 전체 페이지 너비는 넘치지 않게 합니다. 최근 처리순 도구막대도 실제 입출고 표 너비에 맞춥니다.
