폴더 선택 전입니다.

폴더 기억 기능을 지원하면 새로고침 버튼으로 변경된 자료를 다시 읽습니다. 일반 선택 방식은 매번 폴더를 다시 선택합니다.

기본 연결은 읽기 권한입니다. 선택 자료 관리에서 실제 반영을 실행할 때만 쓰기 권한을 요청합니다. 엑셀 백업과 복구용 이미지 사본을 만든 뒤 처리하며, 인터넷으로 전송하지 않습니다.

일주일에 한 번, 이렇게 사용하세요

  1. 새 자료가 생기면 이 대화에서 폴더를 지정해 정리를 요청하세요.
  2. 정리된 엑셀과 이미지를 거래처별_정리 폴더에 보관하세요.
  3. 이 프로그램의 폴더 설정에서 해당 폴더를 선택하세요.
  4. 자료를 업데이트한 뒤에는 자료 새로고침을 누르세요.

폴더 기억을 지원하지 않거나 권한이 만료되면 같은 폴더를 다시 선택하면 됩니다. 폴더를 읽을 때마다 현재 엑셀과 이미지 목록을 다시 확인합니다. 이전 버전의 수정 내용은 이 조회 목록에 덮어씌우지 않습니다.

날짜는 전체 기간이 기본입니다. 거래처는 여러 곳 선택할 수 있고, 날짜·품목 검색과 함께 사용할 수 있습니다.

체크한 문서가 있으면 엑셀 내보내기는 그 문서를 저장합니다. 체크가 없으면 현재 검색 결과 전체를 저장합니다. 선택한 문서는 검색 조건을 바꾸어도 유지되며 ‘선택 해제’로 지울 수 있습니다.

선택 자료 관리에서 관리폴더 통합·거래처명 수정·보관·휴지통 이동을 할 수 있습니다. 이 기능은 폴더 선택 · 기억하기 연결과 쓰기 권한이 필요하며, 변경 전 백업을 남깁니다. 최근 작업 되돌리기는 후속 엑셀 변경이 없을 때 복원합니다. 이미지 복사 저장은 원본을 변경하지 않습니다.

이미지 없음은 엑셀의 경로에 실제 파일이 없거나 연결되지 않은 경우입니다. 회전은 화면에서 보기 방향만 바꾸며 원본에 저장하지 않습니다.

선택한 명세표 관리

이미지와 엑셀을 함께 처리합니다. 변경 전 백업은 _프로그램보관/작업기록에 남습니다. 휴지통은 Windows 휴지통과 별개인 복구용 폴더입니다.
